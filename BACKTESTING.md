# Backtesting status

`strategy_v0_1` remains the preserved partial hypothesis. V1's deterministic baseline rules are defined in `docs/STRATEGY_SPEC.md` and `config/strategy_v1.yaml`, but the causal event/state machine and execution engine have not yet been implemented and validated. The API therefore continues to validate data and report schedules without creating signals, trades, or performance results. V1 must remain `IMPLEMENTATION_PENDING` until the automated implementation checks pass.

V1 prefers provider `spread_pips`, then an explicitly configured fixed fallback; if neither exists, it retains the candidate with `SPREAD_DATA_UNAVAILABLE` and excludes it from executable trades. Before simulation is enabled, tests must cover entry timing, spread source labeling, slippage, commission, stop/target behavior, sizing, gap fills, same-candle ambiguity, DST resolution, and causal state transitions. Evaluation must include independent in-sample, validation, and out-of-sample periods; a transaction-cost matched random baseline; walk-forward testing; Monte Carlo; parameter sensitivity; and stated classification criteria. Historical performance does not guarantee future performance.
