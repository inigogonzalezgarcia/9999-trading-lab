# Contributing

Keep each research assumption visible in a versioned configuration and in `STRATEGY_SPEC.md`. New strategy versions must not overwrite old run configurations. Changes to simulation semantics need deterministic fixtures and tests. Preserve UTC internally and use IANA time zones for wall-clock rules. Never add live broker execution to this research MVP. Run `python -m pytest`, `ruff check backend tests scripts` and `cd frontend && npm run build` before submitting changes. Engine changes must keep `tests/test_m1_completion_gates.py` green; when touching hot paths, compare candidates and portfolio output against the previous version on a labelled synthetic dataset (`python -m backend.cli stress`). Keep the educational notice intact in API, UI and exports.
