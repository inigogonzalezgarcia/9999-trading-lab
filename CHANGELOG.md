# Changelog

## 0.5.1 — 2026-10-30

- Kit card on the home page and the lessons index linking to the Gumroad product (`KIT_URL`, `KIT_PRICE` in `site.ts`); covers in `frontend/public/kit/`, generated by `scripts/kit_cover.py`.
- `scripts/build_kit.py`: builds the paid kit "Cómo leer un backtest" (bilingual PDF guide computed from the real V1/V1.1 results, report template MD+PDF, decision checklist, derived datasets with SHA-256, data download instructions) into `dist/kit/` and a zip. No raw candles are redistributed.

## 0.5.0 — 2026-10-28

- Public educational site (Cloudflare Pages, no backend): `python -m backend.cli export-web` precomputes the
  runs listed in `config/web_runs.yaml` into trimmed JSON (+ PDF) under `frontend/public/data/`; the frontend
  built with `VITE_STATIC_MODE=1` reads them instead of the API.
- Frontend becomes a small site: landing page, lab (catalogue of published results or the local tool), three
  free lessons with real-result widgets, quizzes and graded lab notes (progress in localStorage), Notice/Method,
  legal pages (ES/EN), mailing-list opt-in (Pages Function `/api/subscribe` with Turnstile + KV).
- Whole UI bilingual (ES/EN) with a global language switch; tiny history router (no new dependencies).
- `_headers` (CSP, nosniff, frame-ancestors) and SPA `_redirects` for Pages.

## 0.4.1 — 2026-10-23

- Dukascopy downloader: every complete calendar month is checkpointed to `<out>.parts/<SYMBOL>_<YYYY-MM>.csv`
  and reused on the next run, so an interrupted download resumes instead of restarting; back-off on
  HTTP 429/503 and connection resets is capped at 10 minutes with up to 30 attempts (`Retry-After` honoured);
  default pause 0.3 s between hours; certifi CA bundle used when the Python build has none.
- PDF report: signed bar charts colour losses red, keep category labels under the plot and always start at zero.

## 0.4.0 — 2026-10-22

- Trade explainer: every executed trade carries its M1 candles plus the rule levels (liquidity, sweep extreme,
  zone, BOS, entry, stop, target) and the timestamped rule events (`backend/app/explain.py`,
  `GET /api/runs/{run_id}/trades/{trade_id}/explain`). Clicking a trade in the UI draws them.
- "Notice / Method" page (ES/EN): legal notice, the V1 hypothesis and the research protocol in plain language,
  how to read a result, current state of the research.
- Server-generated PDF report (`backend/app/report.py`, reportlab): cover with notice and reproducibility,
  data, results, time breakdowns, sensitivity (research runs), limitations. `GET /api/runs/{run_id}/report.pdf`
  and `python -m backend.cli report`.
- Metrics: R by entry hour, weekday, month, direction and exit reason (strategy reference timezone), with
  signed bar charts and tables in the UI.
- Instruments: `config/instruments.yaml` + `backend/app/instruments.py` (pip size, Dukascopy point scale,
  contract size). Simulation, ingest and CLI use per-symbol pips; JPY pairs supported. Strategy YAML lists
  which instruments it may trade; `/api/config` exposes them and the UI symbol selector follows the strategy.
- V1 configuration unchanged (bit-identical output); V1.1 instrument list extended.

## 0.3.0 — 2026-10-16

- Strategy V1.1 experiment (`config/strategy_v1_1.yaml`): London-open windows, zone-distal stop, liquidity
  level expiry. Engine parameters default to V1 behaviour (bit-identical); `--strategy` / form field /
  UI selector choose the configuration.
- Sensitivity grid covers stop reference, stop max distance and level expiry.
- PORTFOLIO mode: symbol-aware loader checks, `merge` CLI command, GBPUSD 2024 run.
- `docs/FIRST_REAL_RUN.md` extended with the V1.1 comparison and its fragility table.

## 0.2.1 — 2026-10-16

- First real-data run: Dukascopy EUR/USD 2024 ticks (20.7M) → 372 774 M1 bars; report in `docs/FIRST_REAL_RUN.md`.
- `ingest.read_bi5_bundle` / `convert bundle`: decode monthly `.bi5` bundles saved by a browser.
- Report `timing`: hour-of-day histograms of sweep confirmations and complete setups (UI section).
- Sensitivity study accepts labelled multi-key variants; default grid adds London/New York session experiments.

## 0.2.0 — 2026-10-15

- Engine split into `backend/app/strategy/` with numpy hot paths; bit-identical output, ~40× faster.
- Fixed crash sorting candidates without execution time; fixed per-trade Sharpe annualisation.
- New `metrics.py` (per-trade vs daily-series statistics, equity curve) and `research.py` (splits,
  walk-forward, Monte Carlo, sensitivity, cost-matched random benchmark).
- Data acquisition: HistData and Dukascopy converters, Dukascopy tick downloader, labelled stress generator.
- SQLite run history, background jobs with progress, upload limits, CORS/env configuration, CSV/JSON exports.
- CLI (`python -m backend.cli`): fetch, convert, validate, backtest, research, runs, stress.
- React dashboard: KPI tiles, equity curve, candles with trade markers, sortable trades, rejection breakdown,
  research report, history, print-to-PDF; pinned dependencies.
- Educational notice embedded in API, results, UI and exports; `DISCLAIMER.md`; documentation synchronised;
  CI with Python matrix, ruff, frontend build and Docker build; pinned Python requirements.

## 0.1.0 — 2026-10-07

- Initial scaffold: data import and quality checks, UTC/DST handling, Strategy V1 specification and causal
  engine with completion gates, minimal API and UI.
